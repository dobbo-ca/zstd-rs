## decodecorpus/

The contents of zstd-go's `testdata/decodecorpus.tar.gz` extracted (the tests have no gzip): 304
`<name>.zst` / `<name>.orig` pairs generated by decodecorpus from facebook/zstd, same licence as
above.

## klauspost/

Copied unchanged from zstd-go; see `klauspost/LICENSE.md`.

## tiles/

zstd-go's synthetic tile fixtures, copied unchanged (`<format>_<size>_<content>_z<level>[_hilo].zst`,
see its `testdata/tiles/gen.go`; `_hilo` ones hold the low and high byte planes, as CZI zstd1
does). The tests decode them against the size in the file name; they are also the benchmark input
(`examples/bench.rs`, `tests/parity/bench.sh`) and the czi parity inputs.
